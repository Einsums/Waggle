============
Command line
============

``waggle`` opens the viewer; ``waggle report``, ``waggle diff`` and ``waggle cpu`` read saved sessions without it, and ``waggle calibrate`` measures the machine for ``waggle cpu``.
``python -m waggle`` is the same command.
